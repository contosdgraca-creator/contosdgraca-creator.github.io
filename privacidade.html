Política de privacidade

Atualizada em 26 de outubro de 2026

Esta política vale para o Reddit Shorts Bot, a ferramenta interna que o canal ContosdGraça usa para enviar vídeos ao YouTube.

Quem usa a ferramenta

Somente o dono do canal ContosdGraça, no próprio computador. A ferramenta não é oferecida, vendida nem distribuída a outras pessoas.

Quais dados do Google a ferramenta acessa

  • Permissão pedida: enviar vídeos ao YouTube (escopo youtube.upload).
  • Ela é usada apenas para publicar vídeos no canal ContosdGraça, com título, descrição e tags definidos pelo próprio canal.
  • A ferramenta não lê, coleta nem guarda dados de outros usuários, inscritos, comentários ou mensagens.

Onde ficam as credenciais

O código de autorização do Google fica salvo apenas no computador do dono do canal. Ele não é enviado a servidores de terceiros nem compartilhado.

Compartilhamento

Nenhum dado obtido pelas APIs do Google é vendido, transferido ou usado para publicidade. O uso segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de uso limitado.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Os vídeos enviados ao YouTube seguem os Termos de Serviço do YouTube e a Política de Privacidade do Google.
